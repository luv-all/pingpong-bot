# 7/31 Eval Protocol (sim GUI)

**날짜:** 2026-07-26  
**상태:** implementing

## Goal

시뮬 Shooter 패널에서 **좌 10 / 중 10 / 우 10** 발사를 돌려  
0~3점 루브릭으로 합산(만점 90, 통과 **>45**)을 보여 준다.

## Scoring

| 점 | 조건 |
|----|------|
| 0 | 미타격 |
| 1 | 접촉만 |
| 2 | 접촉 + 네트 통과 |
| 3 | 네트 통과 + 상대 코트 착지 |

## Protocol shots

- **Block:** 왼×10 → 중×10 → 오×10
- **Alternating:** 왼→중앙→오→중앙→왼→… (존당 10발)
- 존 안 목표 x: 로봇쪽 테이블 해당 1/3 구간
- 속도·pitch·height는 패널 슈터 설정 (네트 미달 시 pitch +0.5~3°)
- roll/spin = 0
- 헤드리스 `SimWorld` 백그라운드 스레드

## UI

- 버튼: `7/31 Eval (30)`
- 진행: `n/30`
- 결과: 총점 /90, Pass/Fail, 존별 합·점수 분포(0/1/2/3)
