# 손목·리니어 레일 2단계 제어

## 목적

현재 실기 제어는 전체 팔로 공을 타격하지 않는다. 카메라 예측에 따라 리니어
레일이 움직이는지 확인하고, 예측이 안정되면 손목축 하나만 시험 구동한다.

## 입력

추정기는 다음 정보를 제어 워커에 보낸다.

```text
CommitRequest {
    track_seq,
    trajectory: BallTrajectory,
    stage: Provisional | Refined,
    at,
}
```

`track_seq`는 공이 바뀌었음을 명시한다. 새 번호를 받으면 이전 공의 단계 상태를
버리므로, 이전 공이 정밀 단계까지 도달하지 못해도 다음 공을 정상 처리한다.

## 단계 판정

1. EKF가 위치와 속도를 추정하고 목표를 선택하면 `Provisional`이다.
2. 첫 정상 3D 관측 후 0.25초 이상 지나고, 최근 목표 세 개가 최신 목표에서
   10cm 이내이면 `Refined`다.

예측 공분산은 화면 진단에는 표시하지만 제어 시작 게이트로 사용하지 않는다.

## 출력

| 단계 | 리니어 레일 | 손목 ID 5 | 다른 관절 |
|---|---|---|---|
| `Provisional` | 목표 x로 이동 | 준비각 유지 | 명령하지 않음 |
| `Refined` | 정밀 목표 x로 이동 | 준비각 +15° | 명령하지 않음 |

레일 목표는 물리 범위 `0.000~1.410m`로 제한한다. 현재 포즈에서
레일 가속·최고속도와 손목 최고속도를 적용해 최소 필요 시간을 먼저 계산한다.
공 도착까지 남은 시간이 그보다 짧으면 명령을 보내지 않는다. 명령 시간은
기본적으로 `0.05~0.30초`를 쓰되, 실제 최소 이동 시간이 더 길면 그 값을 쓴다.

## 명령 후 실측 오차

실기 제어 워커는 예상 도착 시점부터 20ms 간격으로 레일 엔코더와 손목 ID 5를
다시 읽는다. 두 축이 허용 오차 안에 두 번 연속 들어와야 `converged`로 인정한다.
예상 도착 후 500ms까지 수렴하지 않으면 `timeout`이다.

```text
rail_commanded_m
rail_measured_m
rail_commanded_minus_measured_m
wrist_commanded_rad
wrist_measured_rad
wrist_commanded_minus_measured_rad
```

명령 시점에는 `requested`(제어기 요청)와 `applied`(하드웨어 clamp·틱 양자화 후
실제 전송)도 따로 남긴다. 오차는 `applied - measured`로 계산한다.

레일 절대 오차가 20mm, 손목 절대 오차가 3°를 넘으면 `WARN`, 그 안이면
`INFO`로 기록한다. 이전 명령이 수렴하기 전에 정밀 명령이 나가면 직전 포즈를
`superseded`로 남기고 새 명령을 시작한다. `timeout`이 3회 연속 나면 레일을 정지하고
손목을 현재 위치에 홀드한 뒤 제어 워커를 종료한다.

## 실기·시뮬레이션 공통 경계

`DirectController`가 목표 선택, 레일 범위 제한, 단계별 손목각, 명령 시간을
한 번만 계산한다. 실기 워커와 GUI 시뮬레이션은 모두 이 `DirectControlCommand`를
받고, 차이는 결과를 적용하는 하드웨어 어댑터뿐이다. `SimHardware`도 같은
`Hardware::command_rail_and_racket` 경계를 구현한다.

## 현재 제외한 기능

- 전체 자세 IK
- 라켓 법선과 타격 속도 계산
- 관절별 스윙 궤적
- 백스윙·임팩트·팔로스루
- 자동 센터 복귀
- 스윙 커밋·포기 상태 머신

전체 궤적 플래너는 시작 시 선택적 홈 이동에만 사용한다.
