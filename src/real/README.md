# `src/real` — 공 위치·높이 단순 정렬

`--mode real` 런타임은 카메라로 공을 추적하고, 예측 접수점 `(x, y, z)`에
라켓 중심을 이동시킨다. 현재 단계의 목적은 타격이 아니라 실물 좌표계와 로봇
정렬 정확도를 확인하는 것이다.

## 현재 실행 동작

1. 카메라와 추정 워커를 시작하기 전에 레일을 `0.71m`, 관절을
   `READY_JOINTS_4DOF` 중립 자세로 이동한다.
2. EKF 궤적에서 접수 구간 `y=0.08~0.35m`의 목표를 선택한다.
3. 공 x 주변의 레일 후보를 훑으며 위치 전용 IK를 계산한다.
4. 현재 자세에서 이동이 작고, 관절·토크·레일·테이블 한계를 모두 만족하는
   정지→정지 궤적을 고른다.
5. 레일과 전체 관절을 한 궤적으로 함께 움직인다.
6. 라켓 중심을 원래 예측 `(x,y,z)`에 정지 정렬한다.
7. 정렬 이동이 끝나면 최초 중립 자세로 복귀한다.

라켓 면 방향은 상대 네트 중앙으로 고정한다. 백스윙·전진 타격·팔로스루는
사용하지 않는다.
보존된 스윙 플래너는 다른 진단에서만 사용되며 이 실기 경로에서는 호출하지 않는다.

## 실패 처리

- 위치 IK 또는 안전한 이동 궤적이 없으면 해당 공만 건너뛴다.
- 같은 `track_seq`는 반복 명령하지 않고 다음 공에서 다시 시도한다.
- 중립 복귀가 테이블을 스치면 상승 중간 자세를 포함한 안전 경로를 먼저 계산한다.
- 안전한 전체 경로가 없으면 모터 명령을 보내지 않고 현재 자세를 유지한다.
- 통신·하드웨어 명령 오류만 제어 워커를 종료한다.

## 로그

정렬 명령에는 다음 값이 기록된다.

- `target_x/y/z`: 카메라·추정기가 선택한 공 위치
- `rail_commanded_m`: 선택한 레일 위치
- `joints_commanded`: 위치 IK가 계산한 전체 관절 목표
- `alignment_duration_secs`: 한계를 만족하는 정렬 이동 시간
- `hold_secs`: 정렬 자세 유지 시간

정렬 완료 후 복귀 직전에는 commanded, measured,
commanded-minus-measured를 레일과 모든 관절에 대해 기록한다.

## 실기와 시뮬레이션 일치

실기 `control_worker`와 GUI 시뮬레이션은 모두
`Planner::ball_alignment`를 호출한다. 시작·복귀도 모두
`Planner::return_to_center`의 동일한 중립 자세를 사용한다.

프리뷰 상태 패널은 다음 두 상태만 표시한다.

- `IDLE`: 다음 공 대기
- `ALIGN`: 레일·팔 동시 위치·방향 정렬(스윙 없음)

## 파일 역할

| 파일 | 역할 |
|---|---|
| `run.rs` | 카메라·추정·제어 워커 조립과 메인 루프 |
| `camera_worker.rs` | 프레임 캡처와 공 픽셀 검출 |
| `estimator_worker.rs` | 삼각측량, EKF, 목표 선택 요청 생성 |
| `control_worker.rs` | 중복 방지, 위치 정렬, 실측 로그, 중립 복귀 |
| `preview.rs` | 영상·목표·`IDLE/ALIGN` 상태 표시 |
