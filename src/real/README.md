# `src/real` — 공 위치·방향 정렬·후속 팔 보정

`--mode real` 런타임은 카메라로 공을 추적하고, 예측 접수점 `(x, y, z)`에
라켓 중심을 이동시킨다. 현재 단계의 목적은 타격이 아니라 실물 좌표계와 로봇
정렬 정확도를 확인하는 것이다.

## 현재 실행 동작

1. 카메라와 추정 워커를 시작하기 전에 레일을 `0.675m`, 관절을
   `READY_JOINTS_4DOF` 중립 자세로 이동한다.
2. `defaults::vision`의 검출 캐스케이드와 트리거로 `vision::Fit`이 전체
   `vision::Trajectory`를 만든다.
3. 첫 검출 뒤 0.15초 동안 관측을 모은다. 이후 첫 유효 예측에서 공 x 기반의 빠른 레일
   목표를 보내고, 가능한 경우 팔도 함께 예비 정렬한다. 안정 기준 전 갱신은 이동 중인
   레일을 유지하며 팔만 미세 보정한다.
4. 제어 워커가 요청 지연만큼 궤적을 전진시키고 접수 구간 `y=0.08~0.35m`의
   목표를 직접 선택한다.
5. 위치·속도 불확실성 안정 기준을 처음 통과하면 상대 탁구대 중앙 방향을 만족하는
   레일·팔 통합해를 계산해 AXL 목표를 한 번 보정하고, 계산된 팔 자세를 그대로 명령한다.
6. 안정 기준 통과 이후 같은 `track_seq`의 갱신도 레일은 다시 명령하지 않고 팔만
   최신 실측 자세에서 반복 미세 보정한다.
7. 전역 IK의 독립 레일·관절 시드는 CPU 스레드 풀에서 병렬 계산하며, 20ms 안에
   겹친 예측은 최신 하나만 남겨 진행 중 관절 궤적을 갱신한다.
8. 보정된 공 접촉점이 라켓 블레이드 중심보다 0.5cm 아래에 닿도록 정지 정렬한다.
9. 예측 도착 0.40초 전에 q3 손목만 회전해 타격 시점 라켓 면을 25°로 맞춘다. 가속·감속까지 포함한 전체 관절 궤적의 최고속 상한은 모터 무부하 최고속의 95%이며, 스냅에서는 q3만 그 상한을 요청한다.
   예측 도착 시점에 임팩트 자세를 지나고, 이후 0.12초 동안 같은 방향으로 팔로스루한다.
10. 정렬 관절 이동이 남아 있어도 q3 손목 명령이 관절 스트림을 선점한다. q3 한계·토크·테이블 검사를 통과하지 못하면 손목 동작만 생략한다.
11. 예측 도착 시각부터 0.5초 유지한 뒤 현재 모드의 준비 레일 x와 중립 관절 자세로 복귀한다.

라켓 면 방향은 네트 너머 상대편 탁구대 반쪽의 무게중심으로 고정한다. 정렬 후에는
위치 정렬은 수평 법선으로 계산하고, 타격 직전에 q3 손목만 돌려 25°를 만든다.
실물 손목 q3(ID 5)는 2026-08-06 벤치 진단에서 모델 예측 +6.76°와 달리 라켓이
거의 수직으로 확인돼, `DynamixelConfig` 영점에 -8° 장착각 보정을 적용한다.

## 구간 제어 모드

프리뷰 키 `1`·`2`·`3`은 안전 레일 범위 `0.0100~1.3395m` 기준으로
각각 0~45%(`0.0100~0.6083m`), 20~60%(`0.2759~0.8077m`),
55~100%(`0.7412~1.3395m`) x 구간의 공만 제어한다. 시작·타격 후 대기 위치는 각각 안전 범위의 16%
(`0.2227m`), 50%(`0.6748m`), 83%(`1.1135m`)다. `4`는 중앙 `0.6750m`로 복귀하고
필터를 해제해 모든 공을 받는 기본 모드다. 모드와 관계없이 전체 팔·레일은
상대편 무게중심을 향하는 수평 법선 자세로 예측 공 높이보다 1.5cm 위에 먼저 정렬한다.
타격 직전에 q3 손목만 돌려 라켓 면을 수평 기준 25° 위로 맞춘다.

## 실패 처리

- 위치 IK 또는 안전한 이동 궤적이 없으면 해당 공만 건너뛴다.
- 같은 `track_seq`는 안정 기준 전·후 모두 공 도착 전까지 팔 미세 보정에 사용한다.
- 리니어 레일은 검출 0.15초 뒤 첫 유효 예측에서 한 번, 안정 기준을 처음 통과할 때 정확한 중앙
  방향 목표로 한 번만 보정한다.
- 정렬·복귀 중 다른 `track_seq`가 생겨도 현재 상태를 덮어쓰지 않는다.
- 중립 복귀가 직접 경로에서 실패하면 작은 엔코더 한계 초과를 보정하고
  상승 중간 자세를 포함한 안전 경로를 다시 계산한다.
- 안전한 전체 경로가 없으면 모터 명령을 보내지 않고 현재 자세를 유지한다.
- 통신·하드웨어 명령 오류만 제어 워커를 종료한다.

## 로그

정렬 명령에는 다음 값이 기록된다.

- `target_x/y/z`: 제어가 새 비전 전체 궤적에서 선택한 공 위치
- `request_age_secs`: 채널 지연을 `at_time` 보정에 반영한 시간
- `sigma_position_m`: 선택 위치의 축별 1σ
- `rail_commanded_m`: 선택한 레일 위치
- `joints_commanded`: 위치 IK가 계산한 전체 관절 목표
- `alignment_duration_secs`: 한계를 만족하는 정렬 이동 시간

정렬 완료 후 복귀 직전에는 commanded, measured,
commanded-minus-measured를 레일과 모든 관절에 대해 기록한다.

## 실기와 시뮬레이션 일치

실기 `control_worker`는 첫 본 예측에 `Planner::ball_alignment`를 사용하고,
후속 팔 보정에 `Planner::ball_alignment_fixed_rail`을 사용한다. 시작 초기화는
`Planner::return_to_center`의 기본 레일 x를 사용하고, 자동 복귀와 수동 구간 전환은
`Planner::return_to_center_at`으로 현재 모드의 준비 x를 사용한다.

프리뷰 상태 패널은 다음 두 상태만 표시한다.

- `IDLE`: 다음 공 대기
- `ALIGN`: 예비 레일 즉시 이동·팔 보정, 안정 본 예측 레일 1회 보정, 팔 실시간 보정, 타격 0.40초 전 q3 손목 25° 고속 스냅

## 파일 역할

| 파일 | 역할 |
|---|---|
| `run.rs` | 카메라·추정·제어 워커 조립과 메인 루프 |
| `camera_worker.rs` | 프레임 캡처와 새 `vision::Detector` 후보 검출 |
| `estimator_worker.rs` | `vision::Fit` 일괄 탄도 적합과 전체 궤적 전달 |
| `control_worker.rs` | 중복 방지, 위치 정렬, 실측 로그, 중립 복귀 |
| `preview.rs` | 영상·목표·`IDLE/ALIGN` 상태 표시 |
